# AI answer engines (GEO)
#
# These are listed explicitly rather than left to the wildcard because several
# of them treat an absent explicit rule conservatively, and because being
# quoted in ChatGPT / Claude / Perplexity / Google AI Overviews answers is a
# primary acquisition channel for this site — not a side effect.
#
# Two distinct kinds of bot are allowed here:
#   - Retrieval/citation bots (OAI-SearchBot, PerplexityBot, Claude-SearchBot,
#     Applebot-Extended): these fetch pages to answer a live user question and
#     cite the source. This is the traffic you want.
#   - Training crawlers (GPTBot, ClaudeBot, Google-Extended, CCBot): these feed
#     model training corpora. Allowing them makes the brand more likely to be
#     recalled without a citation.
# If you ever decide you want citations but not training use, disallow the
# second group and keep the first.
# ---------------------------------------------------------------------------

# Deliberately NOT disallowing /thank-you/ or ?gclid= / ?utm_ URLs here.
# Those pages carry <meta name="robots" content="noindex"> and self-referencing
# canonicals, and a crawler has to be allowed to fetch a page in order to read
# those tags. Disallowing them in robots.txt would suppress the crawl, leave
# the noindex unread, and let the URLs get indexed title-only — the exact
# outcome the rule was meant to prevent.
